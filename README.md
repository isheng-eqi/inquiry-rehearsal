# 问询函预演 · Inquiry Rehearsal

监管问询之前，年报里已经写着答案。这个项目把 20 家上市公司的年报和真实交易所问询函放在一起，让系统在读到问询函之前，先从年报里找出"会被问的地方"，每条结论带原文引用和页码。

## 一个能复核的例子

联创光电 2025 年年报第 25 页：

> 预付款项 73,264,393.12 元，上期 13,482,147.33 元，变动比例 **443.42%**

交易所问询函第一条：

> 公司 2025 年末预付款项余额 0.73 亿元，同比增长 443.42%……第一、二名预付对象南昌朝玉京、江西达一特……

同一个数字，同一个对象。系统在读到问询函之前就标出了它（第 25 页、第 139 页）。

## 结果

20 家公司、4532 页年报、143 个真实问询问题。严格匹配（结论是否正面回答某个问题）：

| 方法 | 问题命中 | 结论被支撑 |
|---|---|---|
| 裸模型（年报前 3 万字） | 7/143（5%） | 16/51（31%） |
| 规则层（数值异常） | 3/143（2%） | 3/16（19%） |
| 检索 + 模型 | 31/143（22%） | 70/158（44%） |
| **关注点驱动（留出集）** | **29/72（40%）** | 71/122（58%） |

留出集：只用 8 家公司的问询问题归纳关注点，在 10 家没见过的公司上验证，命中从 31% 提到 40%。

补充指标：人工抽审 20 条结论，误报 3 条（15%）；模型提出的引文 57% 能在原文定位，其余丢弃。

## 方法

1. **算**：收入、应收、预付、存货、在建工程的同比与占比，从年报表格抽，规则触发；
2. **读**：按关注点检索年报段落，模型判断异常并引原文；页码由系统在全文检索定位，引文找不到的结论直接丢弃；
3. **学**：从训练集问询函归纳监管关注点（名称 + 检索关键词 + 监管追问什么），驱动下一轮检索。

## 快速开始

```bash
pip install requests pymupdf beautifulsoup4 playwright pillow
python tools/build_dataset.py        # 从巨潮下载 20 家年报与问询函回复（约 89MB）
python tools/extract_questions.py    # 抽出 143 个问询问题
export DS_KEY=...                    # DeepSeek API Key
python tools/llm_judge.py --mode b2  # 检索 + 模型基线
python tools/learn_concerns.py       # 从训练集学关注点
python tools/llm_learned.py          # 在留出集上跑
python tools/evaluate_all.py         # 三基线汇总
python tools/build_demo.py           # 生成 59 秒演示
```

## 目录

```
tools/            数据、检测、评测、演示脚本
data/             清单、问题、关注点、结果（原始 PDF 不入库）
submission/       设计文档、实验记录、演示视频、证据截图
```

## 边界

- **40% 不是行业水平**，只是本项目在 10 家留出公司上的数字；
- 60% 的问询问题没有答上，很多问题需要业务推理，不是检索能解决的；
- 问询问题由回复函自动抽取，混入了回答段落，分母偏大；
- 检测目前是 Python 管线，尚未注册为 MCP 工具；Nexent 侧只做编排；
- 所有结论只陈述年报原文与数字，不判断"造假"，不构成投资建议。

## 数据来源

巨潮资讯网公开披露的年报与问询函回复。原始文件不入库，`tools/build_dataset.py` 可重新下载。
