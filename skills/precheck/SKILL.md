# Skill：年报预检（precheck）

## 何时用
用户给出公司代码，要求"查一下这家公司年报里可能被问的地方"。

## 输入
- `code`：6 位公司代码，如 600363。

## 步骤
1. 调 `precheck(code)` 取结论列表（问题、页码、原文）；
2. 若要核对，调 `get_page_text(code, page)` 取原文；
3. 按关注点分组输出，每条保留页码与引文。

## 输出
Markdown 列表：`[关注点] 问题（第 N 页）` + 原文摘录；末尾声明"仅基于年报原文，不构成投资建议"。

## 不要做
- 不要补写年报里没有的数字；
- 不要把"披露不充分"写成"造假"。
